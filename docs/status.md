# Development status

This is a five-product application reference with local persistence, collaborative editors and bring-your-own-key Copilot support.

Implemented: five real editor hosts with expanded [authoring profiles](office-features.md); native grid Ribbons for Sheets, Docs and Slides; native Base and Board workbenches; a persistent workspace; six non-secret provider configurations with ephemeral page keys and optional local DeepSeek environment configuration; direct-edit tools; private conversations and confirmed per-turn modifications; SDK file history preview/restore; and separate file and conversation links.

The [AI authoring adapter](ai-authoring.md) adds automatically loaded core/product skills, 15 bundled references, with primary guides loaded automatically and specialized topics on demand, version-matched API lookup, official asset lookup/cache, structured inspection, isolated backend Facade scripts, legacy JSON plans, saved-head verification, official Markdown and Typst document compilers, SVG slide compilation with browser text metrics, real PNG previews and layout checks. Generated source and preview metadata support subsequent repairs. The agent remains LangChain-based; these are Univer AI SDK capabilities.

## Default cases

The local process entry seeds [six editable native examples](../README.md#included-examples) for each new demo account: six Anthropic IPO files across all five products and both document flavors. The Base case includes three dashboards and fifteen live charts. These are private copies with fresh file/Unit identities and revision one; existing accounts and edits are never reset. Conversation history, previous versions, attachments, sharing grants, model profiles and credentials are not part of the bundled snapshots. `DEMO_EXAMPLES=false` restores empty-workspace onboarding. Regular registration and login do not seed cases.

## Restore verification · 2026-11-04

A real browser restore exposed an application adapter defect: the server submitted a restore using an idle worker's member identity, producing an unexpected ACK. Its error listener had already been detached, so a late worker error could stop the host. Restores now execute the public SDK `RevertRevisionMutation` through the joined client and wait for its normal ACK; worker error listeners remain attached through termination.

The active-editor browser regression and all 35 application tests pass. A real DeepSeek-generated Modern report was restored to its initial blank version, reopened, then restored to its generated version and reopened again. Native content/counts returned, version history remained, chat/message hashes and per-turn modification records were unchanged, and the Markdown mapping checkpoint was recovered. These are whole-file restores; the turn dialog currently provides modification/version viewing, not selective per-turn undo.
